# Studio shell (src/App.tsx)

Mode: Operate. Audience: public creators using the claude-animated-shorts skill. Structure pinned by user: sidebar with Guide (Introduction, How to use, Requirements) + per-short Pipeline steps; Library and agent dock as supporting surfaces. Visual world kept (user: "keep, but fix and tighten"). Code-led.

## Direction contract

THESIS: The app is the skill's SKILL.md made operable: one sidebar that reads top to bottom as the pipeline. Refuses the 3-pane dashboard and the pill-stepper wizard.
OWN-WORLD: Monochrome zinc glass chrome (quick-liquid surfaces only on sidebar and dock), plain ground for work content, hairline dividers, one emerald accent for the primary action, ready states and progress. Playfair for page titles only, Poppins for UI, mono for paths, commands and logs.
STORY: A first-time user learns what it does, installs what is missing, then walks Topic → Render with each page naming what it produces and which file it writes.
FIRST VIEWPORT: Introduction page: title, one-paragraph explanation, the seven-step pipeline as a readable sequence with outputs, and two actions (Check requirements, Start a short). Sidebar shows requirement status count.
SIGNATURE: Sidebar step list with live done/current state per short; "Send to agent" fills the docked terminal with the exact step prompt.
RISK: Scenes step has no artifact to prove completion; status is inferred from stills/render.
